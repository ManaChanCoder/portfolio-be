# Portfolio - BE

Backend Side of my portfolio-fe

## Installation

```bash
1. clone the backend server
git clone https://github.com/ManaChanCoder/portfolio-be.git

2. Go to the directory
cd portfolio-be

3. Install the dependencies
git install

4. Run the server
git npm run dev

## Usage
- CRUD operation
- Make or add project  from the past the already hosted of frontend
- Edit as well the project
- View Projects
- Edit project 1 by 1
```
